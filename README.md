`dorsal-html-reports` transforms raw JSON payloads generated by [Dorsal](https://github.com/dorsalhub/dorsal) into self-contained, interactive HTML reports.

## Features

* **Zero Heavy Dependencies:** Built purely on standard Jinja2 templates and embedded CSS/JS.
* **Fully Self-Contained:** Output files can be opened directly in any browser without external internet access or CDN reliance.
* **Dual Reporting Modes:**
  * **File Reports:** Individual file metadata inspections (hashes, extracted metadata, raw schemas).
  * **Collection Reports:** Aggregated directory summaries, duplicate tracking, and size distribution histograms powered by bundled Chart.js assets.
* **Interactive UI:** Includes built-in dark/light mode switching, click-to-copy hash utilities, unit toggles, and expandable accordions.

---

## Installation

Install via `pip`:

```bash
pip install dorsal-html-reports

```

Or add it using `uv`:

```bash
uv add dorsal-html-reports

```

## Quickstart

### 1. Generate Single-File Reports

Pass a parsed Dorsal file JSON dictionary or file path to produce an HTML string:

```python
import json
from dorsal_html_reports.api import generate_html_file_report

with open("bill_report.json") as f:
    file_record = json.load(f)

# Save directly to disk
generate_html_file_report(file_record, output_path="report.html")

# Or return the HTML string directly
html_content = generate_html_file_report(file_record)

```

### 2. Generate Collection / Directory Reports

Generate a report summarizing multiple scanned files or directory payloads:

```python
import json
from dorsal_html_reports.api import generate_html_directory_report

with open("scan-dir-testmix_report.json") as f:
    collection_data = json.load(f)

# Save directly to disk
generate_html_directory_report(collection_data, output_path="collection_report.html")

# Or return the HTML string directly
html_content = generate_html_directory_report(collection_data)

```
